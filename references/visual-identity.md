# Visual Identity

The `antigravity-gemini-bridge` skill uses a distinct visual theme to represent the collaboration between Codex and Gemini.

## Theme Details

- **Concept**: Cute cuddle style, two abstract AI companions leaning together.
- **Colors**:
  - Gemini Companion: Teal/Mint (`#20B2AA`) with subtle rabbit ears.
  - Codex Companion: Sky Blue/Navy (`#4682B4`), leaning toward the mint companion.
  - Accent: A tiny Amber sparkle (`#FFC000`) symbolizing ideas/insights.
- **Background**: Transparent for clean SVG rendering across dark and light themes.

## Assets

- `assets/icon-small.svg`: Used for the small skill icon in lists.
- `assets/logo-large.svg`: Used for the large header logo in the skill view.

*Note: We do not use official OpenAI or Google logos. The icons are original, simple vector shapes.*
